Designed and developed a full-stack Food Ordering and Management System using Go (Golang), Gin Web Framework, and MySQL.

Key features:

Developed REST APIs for customer, menu, order, and administrative operations.

Implemented a role-based system supporting Customers, Cashiers, and Administrators.

Developed food ordering functionality, allowing customers to browse menus, place orders, and track order progress.

Implemented order tracking with multiple status stages, including Pending, Accepted, Preparing, Ready, On the Way, Delivered, Closed, and Cancelled.

Developed administration modules for menu management, user management, and order processing.

Implemented reporting features, including Sales Reports, Menu Performance Reports, Customer Order Reports, and Filtered Order Reports.

Applied Layered Architecture, Dependency Injection, Service Layer Pattern, and Repository Pattern.

Implemented session-based authentication, password hashing, and role-based authorization.

Designed a modular and maintainable application structure following modern software engineering practices.

Technologies: Go (Golang), Gin Framework, MySQL, REST APIs, Layered Architecture, Dependency Injection, Repository Pattern, RBAC, Session-Based Authentication, Git.
